# Personal Portfolio Website

This is my personal developer portfolio built using **HTML, CSS, and JavaScript**.  
It showcases my projects, skills, and contact information in a clean and responsive layout.

The website is deployed using **GitHub Pages** and serves as a central place to present my work and frontend development skills.

## 🌐 Live Website

Visit the live portfolio here:

https://amaan1416.github.io/portfolio-webite/

## 🚀 Features

- Responsive design (works on mobile, tablet, and desktop)
- Smooth scrolling navigation
- Animated sections on scroll
- Modern UI layout
- Interactive project cards
- Working contact form using Formspree
- Social links to GitHub and LinkedIn

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages (for deployment)
- Formspree (for contact form)

## 📚 What I Learned

While building this project I practiced:

- Creating responsive web layouts
- Structuring a complete frontend project
- Deploying websites using GitHub Pages
- Integrating a working contact form
- Improving UI with animations and hover effects
